# Contributing during provenance and scientific review

The lab is currently conducting an authorship, provenance, technical-verification and publication audit. Discussions identifying errors, reproducibility gaps, antecedent work and validation methods are welcome.

**Please do not submit substantial new source code, figures, datasets, text or potentially patent-sensitive implementations before the maintainers publish a contributor-rights policy.** Unsolicited submissions do not convey ownership or licensing rights to the project.

When contributions are opened, proposals must identify authors and material sources, the applicable third-party licenses, AI-assistance scope, employer/client confidentiality constraints and the right to contribute. The project will decide whether to use a Developer Certificate of Origin for an open-source track, or counsel-reviewed contributor terms for any dual-commercial-licensing track.

Do not add undisclosed provider secrets, local machine identities, proprietary employer data, patient/customer information or private agent transcripts to issues, pull requests or CI logs.

No blanket permission to relicense project files is granted by this document. See [Rights and Reuse](RIGHTS_AND_REUSE.md).
