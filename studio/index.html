The network on K₈

Pair angles, their gradient part and what fails to close

Each edge carries one measured angle difference Δαij = αi − αj, read from the ratio of antisymmetric to symmetric cross-spectra. The common rotation (β and any shared offset) cancels. The gauge-fixed fit splits the 28 numbers into a gradient part (7 dimensions, one angle per map) and a remainder. With every triangle filled, H¹ = 0, so there is no harmonic part: the remainder is triangle-closure failure. The fit is weighted by the edge covariance C, so the remainder is a covariance-weighted coexact component (C⁻¹r ∈ im d₁ᵀ). This graph “curl” is a calibration diagnostic, unrelated to CMB B-modes.

Verification

Every kernel checked in a network-less sandbox

Numerical kernels are numpy-only by design so they run in the JoVin container (no network, Python + numpy, 10 s limit). The verifier bundles the exact shipped functions via ast, never hand-copied, and each run appends a hash-chained receipt. Full-resolution steps (ducc0 transforms, FITS input) cannot run there; they are covered by local tests, including an end-to-end injection on synthetic HEALPix maps.
